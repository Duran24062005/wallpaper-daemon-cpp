# Documentación

Esta carpeta explica la arquitectura y el camino de evolución de
`wallpaper-daemon-cpp`. Está escrita como tutorial: cada componente existe por
una razón, recibe unas entradas y entrega un resultado.

## Ruta recomendada

1. Leer [`Architecture.md`](Architecture.md) para entender el flujo actual.
2. Leer [`../README.md`](../README.md) para ejecutar y ubicar el proyecto.
3. Seguir los PRDs en [`../prds/README.md`](../prds/README.md).
4. Contrastar cada etapa con [`wallpaper-rs`](../../wallpaper-rs/README.md).

## Documentos

- [Arquitectura](Architecture.md): módulos, flujo de datos, límites y equivalencias.
- [PRDs](../prds/README.md): evolución paso a paso desde el MVP hasta las capacidades de Rust.
